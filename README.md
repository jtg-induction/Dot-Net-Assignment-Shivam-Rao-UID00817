# RESTAURANT MANAGEMENT SYSTEM



## Objective

Develop a robust, API-driven backend solution to optimize the order management process for restaurants. 



It features three distinct user roles:



* **Customers:** To browse restaurant menus and place orders seamlessly.

* **Restaurant Owners:** To efficiently manage, track, and update the status of incoming orders.

* **Super Admins:** To onboard new restaurants and manage user access.



Additionally it also generates reports to support analytics, ensuring restaurant owners can make data-driven decisions.





## Tech Stack:



* .NET Framework 4.8

* SQL SERVER with ADO.NET and Entity Framework

* Telerik / Crystal Reports

* NUnit / MSTest

* IIS Hosting

* Swagger (for API exploration and testing)

## Required Software:
* Visual Studio
* Microsoft SQL Server Management System
* .NET Framework 4.8


*Coding standards to be followed:*

* *Use Pascal Case for naming the tables and their respective fields*
